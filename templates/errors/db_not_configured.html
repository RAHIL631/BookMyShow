Almost Ready! 🚀

BookMySeat is successfully deployed to Vercel, but it needs a PostgreSQL Database to store and show movie data.

1. Create Storage: Go to the Storage tab in your Vercel Dashboard.
2. Link Postgres: Create a Vercel Postgres instance and click "Link" to connect it to this project.
3. Redeploy: Go to the Deployments tab and click "Redeploy".

The application will automatically detect the database and run migrations on next launch.
